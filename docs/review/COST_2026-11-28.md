1. Выбран самый дорогой текстовый режим (gpt-5.5 + effort high) без оценки стоимости и без вопроса автору.
2. Запущено 10 параллельных потоков — бюджет сгорел за ~10 минут, без точки остановки.
3. Ценность критика оказалась умеренной: русские правки на ~40 % отклонены, финальное решение по каждой всё равно принимал шоураннер.

## Как дальше
- Текстовую проверку (оставшиеся 39 партий EN) делать без OpenAI: шоураннер читает сам по глоссарию и стоп-листу.
- Деньги OpenAI — только на картинки: ~21 новый кадр + переделки; каждую партию согласовывать, перед запуском называть число кадров.
- Если всё-таки критик через API: effort low/medium или gpt-5-mini, 1 поток, сначала одна пробная партия с отчётом о стоимости.
