## Как продолжить в новой сессии

Автору достаточно написать: **«Открой репозиторий Basker24/quantum-quest, прочитай CLAUDE.md и docs/04_status.md и продолжаем»**.

Claude в новой сессии:
1. Читает в таком порядке: `CLAUDE.md` → этот файл → `docs/01_canon.md` (канон, пп. 1–25) → `docs/03_style.md` (голос) → нужные разделы `docs/02_bible.md` (§1 решения конфликтов, §10 поправки v0.2 приоритетнее остального).
2. Сверяется с `docs/generated/report.md`: шапки сцен, диапазоны переменных.
3. Продолжает с раздела «Очередь» ниже.


## Где что

| Что | Где |
|---|---|
| Репозиторий | `Basker24/quantum-quest`, ветка `main` |
| Игра онлайн (приватная) | https://claude.ai/artifact/B42euDmPxhkzjUEwHajnLP |
| Обновить игру онлайн | Artifact → publish с `url` выше, `file_path` = `game/play.html`, `files` = `{style.css, engine.js, graph.js}` из `game/`. Из новой сессии сначала `action: read` этого url |
| Исходники сцен | `scenes/*.md` (формат — в шапке `tools/qqparse.py`), переменные и флаги — `scenes/_config.json` |
| Сборка | `python3 tools/build.py` → `game/graph.js` и `game/play.html` |
| Проверка логики | `python3 tools/validate.py` — быстрая интервальная проверка (0,3 с): диапазоны, I2, локальный I1 с перестраховкой. `--exact` — точный перебор всех состояний (тяжёлый, сам переключается на быстрый при > 300 тыс. узлов) → `docs/generated/report.md` |
| Проверка в браузере | `node tools/e2e.js [папка]` — ствол → В2 с капканом и шоком; `node tools/e2e_life.js [папка] [dive|river]` — целая жизнь до финала |
| Пути к финалам (свидетели) | `python3 tools/witness.py` → `docs/generated/witness.md`; `build.py` сам встраивает их в игру (`GRAPH.guides`, подсказки — `scenes/_guides.json`). `node tools/witness_play.js` проигрывает каждый путь в движке. `build.py --no-witness` — без поиска |
| Переименовать сцену | `python3 tools/rename.py СТАРЫЙ НОВЫЙ` |
| Задания агентам | `docs/prompts/` (литредактор, критик) |

## Как работаем над партией сцен

1. Пишу сцены по канону, библии и стайлгайду. У каждого выбора есть `## После X`; у каждой смерти — конкретный текст и `## Пробуждение`.
2. `build.py` → `validate.py`: 0 ошибок I1′/I2/C6. Предупреждения разбираю.
3. Литредактор — фоновый агент по `docs/prompts/editor.md`. Его «сомнительные факты» исправляю или выношу сюда.
4. `node tools/e2e.js` и скриншоты ключевых экранов.
5. Публикую в артефакт, делаю коммит и push.
6. **Обновляю этот файл.**

## Известные проблемы и долги

- **Валидатор:** точный перебор всей жизни не помещается в память (миллионы состояний), поэтому по умолчанию — быстрая интервальная проверка. Её диапазоны с запасом (переменные независимы, напр. ДАР «0–100» на якоре при реальных ~85), I1 проверяется локально без учёта отката. Идея на будущее: точный перебор по отрезкам (ствол / ветвь / якорь) с проекцией на границах.
- **Условия в секциях «После»** валидатор пока не проверяет на I2. Проверяет только синтаксис.
- **Т-10** допускает до 7 вариантов при правиле 2–5. Это осознанное исключение (выбор жизни), автор пока не возражал.
- **Фото:** везде заглушки. Промпты есть в `photo_prompt` каждой сцены, файлы кладутся в `game/img/<ID>.jpg`; план генерации — раздел «Картинки (план)».
- **Не решено после литредактора:**

  - морозы −42 в Томске 14.01.2009 исторически не проверены.
- **В2-07:** по тексту отец работает «горизонтом выше» лаборатории (ниже −200), сверить с библией.
- **Путеводитель:** свидетель — один путь на финал (сейчас все через В2); подсказки `_guides.json` упоминают сцены В2.
