**1. Базовый кадр сцены** — `game/img/<ID сцены>.jpg`, ID ровно как в шапке сцены (`id:`), кириллицей, с точками и буквами: `Т-02б.jpg`, `В2.1-04.jpg`, `В2.2-03в.jpg`, `Я-01.jpg`, `Ф-04.jpg`, `⊣К-06.jpg` (знак «⊣» в имени файла — да, как в ID). **2. Вариант по флагу** — если в шапке сцены есть `photo_by: F_ФЛАГ`, движок сначала ищет `game/img/<ID>~<ЗНАЧЕНИЕ>.jpg`, где ЗНАЧЕНИЕ — значение флага на этом пути, ровно как в `scenes/_config.json` (заглавными, с «Ё» и подчёркиваниями): `В1-13~ВЫТАЩИЛ.jpg`, `В7-10~НИКА.jpg`, `Я-01~ВНУК.jpg`. **3. Вариант по нескольким флагам** — `photo_by: F_А, F_Б` (через запятую). Порядок поиска: `<ID>~<ЗНАЧ_А>~<ЗНАЧ_Б>.jpg` → `<ID>~<ЗНАЧ_А>.jpg` → `<ID>~<ЗНАЧ_Б>.jpg` → `<ID>.jpg`. Флаг типа «да/нет» (bool) даёт значение `ДА`: `В2.2-02~ДА.jpg`. Флаг без значения на этом пути пропускается.
