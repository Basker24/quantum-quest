# Название игры: разбор (14.11.2026)

Решение автора: оставить «Тот, кто остался» (канон п. 36).

Сводка трёх независимых разборов:
- **Сценарист:** топ — «Ты чей?», «Двести пятьдесят две», «Четыре двенадцать». Замечание: название совпадает с финалом Ф-01 и делает его «истинным».
- **Филолог:** топ — «Заводь» (EN *Still Water*), «Тот, кто остался» подзаголовком, «Двести пятьдесят две». Риски рабочего названия: запятая, слабый поиск, «Тот, кто остаётся» в «Локи»; сила — пять смыслов «остаться», включая «остался там» = погиб. Не брать: «Откат» (взятка), «Водяной» (песня), «4:12» (библейская ссылка), *The One Who Remains*, *Left Behind*, *What Remains*.
- **Маркетолог** (проверено поиском): «4:12 AM» уже есть в Steam (уголь + 4:12) — «Четыре двенадцать» снят; *Those Who Remain* в Steam; книга Кетро «Тот, кто останется». Свободные домены: blackbackwater.com, 252seconds.com, 252.game, theonewhoremained.com. Топ-пара: «Тот, кто остался. 252 секунды» / *Black Backwater*.
