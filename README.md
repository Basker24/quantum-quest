# Quantum Quest (рабочее название)

Текстовый квест о квантовом бессмертии. Кузбасс, 1996–2061, одна обычная жизнь, в которой герой не может умереть, но очень хорошо помнит, как умирал.

> Статус: **пре-продакшн** — пишем библию игры (лор, сюжет, системы).

## Структура

| Путь | Что это |
|---|---|
| `docs/01_canon.md` | **Канон**: утверждённые решения. Источник истины |
| `docs/00_concept.md` | Концепт-документ: механики, переменные, нумерация, формат сцены |
| `docs/drafts/` | Черновики «сценарной комнаты» (лор, сюжет, геймдизайн) до утверждения |
| `scenes/` | Тексты сцен (`T-01.md` — ствол, `_demo_*` — демо формата, не канон) |

Дальше появятся: `graph.json` (логика игры), `validate.py` (проверка инвариантов), `engine/` (веб-движок).
