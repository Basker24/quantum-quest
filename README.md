# Quantum Quest (рабочее название)

Текстовый квест о квантовом бессмертии. Кузбасс, 1996–2061, одна обычная жизнь, в которой герой не может умереть, но очень хорошо помнит, как умирал.

> Статус: **прототип** — библия v0.2, движок, валидатор, сцены Т-00…Т-02 и демо механики смерти.

## Структура

| Путь | Что это |
|---|---|
| `docs/01_canon.md` | **Канон**: утверждённые решения. Источник истины |
| `docs/00_concept.md` | Концепт-документ: механики, переменные, нумерация, формат сцены |
| `docs/drafts/` | Черновики «сценарной комнаты» (лор, сюжет, геймдизайн) до утверждения |
| `docs/02_bible.md` | **Библия** v0.2: сводный сюжет, лор и системы, решения конфликтов и поправки после аудита |
| `docs/generated/report.md` | Отчёт валидатора: диапазоны всех переменных и флагов на входе в каждую сцену |
| `scenes/` | Исходники сцен (формат описан в `tools/qqparse.py`), `_config.json` — переменные и флаги |
| `tools/` | `build.py` — сборка игры, `validate.py` — проверка инвариантов полным перебором состояний |
| `game/` | Сама игра: открыть `game/index.html` двойным кликом. `?debug` в адресе показывает цифры и условия |

## Как собрать

```
python3 tools/build.py      # scenes/*.md → game/graph.js
python3 tools/validate.py   # инварианты I1′, I2, C5, C6 + отчёт docs/generated/report.md
```

Фото: положить `game/img/<ID сцены>.jpg` (например `game/img/Т-01.jpg`). Пока файла нет, показывается заглушка в стиле эпохи. Промпт для генерации — в шапке сцены, поле `photo_prompt`.
