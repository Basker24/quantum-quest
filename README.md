# Тот, кто остался

Текстовый квест о квантовом бессмертии. Кузбасс, 1996–2061. Каждый раз, когда я умираю, я снова стою за минуту до смерти и помню её.

> **Играть (публичная копия, ZCode Sites):** https://quantum-quest-940t.zai-ai.site — адрес постоянный, обновляется при пересборке. DLC «Объяснение» — пунктом в меню игры или напрямую: https://quantum-quest-940t.zai-ai.site/obyasnenie/obyasnenie.html

> Статус: **полная игра, предрелиз (v2.x)**. Ствол 1996–2007 и 8 жизней (В1 «Как батя» с подветкой «Участок», В2 «Физфак» → В2.1 «Эталон» / В2.2 «Сорок два», В3 «Партия», В4 «Сварной», В5 «Куда угодно», В6 «Голоса», В7 «Остаться»), якорь 28.07.2061, 6 финалов и 10 тупиков. 144 сцены и 76 смертей. Что сделано и что дальше — в `docs/04_status.md`.

## Что внутри игры

- Смерть — не проигрыш. Надгробие, потом лента: держи, чтобы откатиться. Глубина отката зависит от ДАРа. Смерть меняет только память (Журнал, эхо-варианты «Я помню…»), переменные героя — нет.
- ДРЕЙФ: чем чаще ведёшь судьбу ради себя, тем дальше мир «уезжает». Сдвиги мира помечены в тексте.
- Вступление до меню: один экран — Эверетт и квантовое бессмертие (каждый запуск). Тап «В меню» запускает музыку.
- «Моя жизнь»: схема всей игры, по дорожкам жизней и годам. Неоткрытое — в тумане.
- «Пути»: дороги только к финалам, где ты был, и к тем, по которым идёт текущая жизнь (до сегодняшней сцены).
- Тетрадь Хора (Журнал), режим «Одна жизнь» после финала «Сверим часы», режим автора (`?dev`).
- Лор для игроков, со спойлерами: `docs/lore.md`.

## Как собрать и проверить

```
python3 tools/build.py              # scenes/*.md → game/graph.js, play.html, dev.js, guides
python3 tools/build.py --no-dev --no-witness   # быстрая сборка
python3 tools/validate.py           # инварианты I1–I4 (быстрая интервальная проверка) → docs/generated/report.md
python3 tools/validate.py --exact   # точный перебор (долго)
python3 tools/witness.py            # по одному пути к каждому финалу и тупику + через каждую жизнь
node tools/e2e.js                   # прохождение в браузере (Playwright)
node tools/e2e_life.js              # целая жизнь до финала
node tools/dev_jump_play.js         # прыжки режима автора
```

Картинки: `game/img/<ID сцены>.jpg`, варианты по флагу — `game/img/<ID>~<ЗНАЧЕНИЕ>.jpg` (поле `photo_by` в шапке сцены). Промпт для генерации — поле `photo_prompt`.
